# trader-institutional

台股每天收盤後，證交所和櫃買中心會公布三大法人在每一檔股票的買進、賣出和買賣超。這個 skill 把
這些公開數字整理成你用得上的樣子：今天市場上法人整體買還是賣、誰被投信連續買了好幾天、你看中的
那一檔昨天外資和投信站在哪一邊。

它很快，但不早。數字是收盤後才公布的，所以早上看到的是前一個交易日的動向。這裡沒有內線消息，
只有公開的盤後統計；連買連賣只描述過去，不預測之後。每次都要這樣講。

這個資料夾的工具（標準函式庫 Python，不需要金鑰）：

```bash
python3 "${CLAUDE_SKILL_DIR}/inst.py" market                               # 當天市場總額，上市和上櫃，億元
python3 "${CLAUDE_SKILL_DIR}/inst.py" top --group trust -n 10              # 投信買超、賣超前 10 名
python3 "${CLAUDE_SKILL_DIR}/inst.py" stock 2303 --days 10                 # 一檔股票最近 10 個交易日
python3 "${CLAUDE_SKILL_DIR}/inst.py" streaks --group trust --min-days 3   # 投信連買 3 天以上
python3 "${CLAUDE_SKILL_DIR}/inst.py" watch --write                        # 計畫、持股、觀察名單 -> trader/institutional.json
```

每個指令都可以加 `--json`、`--date 2026-10-30`（看那一天）、`--days N`（往回看幾個交易日，
預設 10）。`top` 和 `streaks` 可以加 `--market TWSE|TPEx`、`--no-etf`、`-n`。
`--now "2026-11-02 09:00"` 把時鐘固定在那個台北時間重播：那時還沒公布的數字不會用到。

## 讀什麼、寫什麼

| 檔案／來源 | 內容 |
| --- | --- |
| 證交所三大法人買賣超日報（T86） | `https://www.twse.com.tw/rwd/zh/fund/T86?date=YYYYMMDD&selectType=ALLBUT0999&response=json`，上市每一檔，單位：股 |
| 櫃買中心三大法人日交易資訊 | `https://www.tpex.org.tw/www/zh-tw/insti/dailyTrade?type=Daily&sect=EW&date=YYYY/MM/DD&response=json`，上櫃每一檔，單位：股 |
| 證交所三大法人買賣金額統計表（BFI82U） | 上市的市場總額，單位：元 |
| 櫃買中心三大法人買賣金額彙總表 | 上櫃的市場總額，單位：元 |
| `trader/plan.json`、`trader/portfolio.json`、`trader/watchlist.json` | `watch` 要看哪些代號（跟 trader-news 一樣的來源） |
| `trader/config.json` | `extra_closed`：臨時休市（颱風假）加在這裡 |
| `trader/state/institutional/` | 已公布的日子存在這裡，不會再改，下次不用重抓 |
| `trader/institutional.json` | `watch --write` 寫出的結果 |

名詞照交易所的定義：外資是「外資及陸資（不含外資自營商）」；自營商是「自行買賣」加「避險」；
外資自營商已經算在自營商裡，交易所不把它重複加進合計。數字包含零股、盤後定價和鉅額交易。
張數是股數除以 1,000 後四捨五入；JSON 裡保留原本的股數。

## 哪一天的數字

交易所沒有寫幾點公布。2026-11-02 那天，Yahoo股市用當天數字做的外資買超排行在 16:21 出現。所以：

- 重播（`--now`）：D 日的數字從 D 日 17:00 起才算公布，在那之前用前一個交易日，並說一聲。
- 即時：13:30 收盤後先問今天的；交易所還沒給（回「很抱歉，沒有符合條件的資料!」）就用前一個交易日。
- 休市日（週末、國定假日、颱風假）直接跳過。2026-10-23 薔琵颱風和 10-26 光復節補假都不算交易日，
  連買連賣的天數會跨過它們。

## 步驟

1. 盤前（08:30 前後）跑 `watch`：昨天法人在你的計畫、持股和掃盤標的上怎麼做。跟 `/trader-news`
   一起看，它們講的是同一件事的兩面。
2. 想找標的時跑 `streaks` 或 `top`，把有興趣的代號交給 `/trader-scanner` 和 `/trader-entry`；
   籌碼只是一個參考，進場還是看價格。
3. 對一檔股票有疑問時跑 `stock CODE`，看最近 10 天的逐日數字和合計，不要只看一天。
4. 跟使用者說的時候：說清楚是哪一天的數字、單位是張、這是盤後的公開統計，而且連買連賣不代表明天
   還會這樣。

  日期                    外資      投信    自營商      合計

  2026-10-30（五）      +4,871   -35,438      +380   -30,187
  2026-10-29（四）    -129,272   -44,817    -8,700  -182,789

  2026-10-16（五）      +2,382   -18,367    -3,719   -19,704

8 天（中間跨過颱風假），11-02 投信賣超 17,885 張是全市場投信賣超第 1 名。

同一天的市場總額（`market`）：

| | 上市 | 上櫃 |
| --- | --- | --- |
| 外資 | -735.21 億 | -10.45 億 |
| 投信 | +338.16 億 | -20.46 億 |
| 自營商 | -152.88 億 | +6.98 億 |
| 合計 | -549.93 億 | -23.93 億 |

連買 10 天以上（只看了 10 天），這段期間 +17,616 張；`top --group trust` 的投信買超第 1 名是
台新新光金 2887，+8,641 張。

盤前重播（`watch --symbols 2303 --now "2026-11-02 09:00"`）：11-02 的數字還沒公布，所以用
10-30 的：外資 +4,871、投信 -35,438、自營商 +380，標記「投信連賣 7 天」「投信大賣（賣超第 1 名）」。
離線資料夾只錄到 10-16，所以這次只看了 9 天，工具會說出來。

## 規則

- 數字只來自交易所公布的檔案，不估、不補。哪一天沒有資料就說沒有。
- 永遠說是哪一天的數字。早上看到的是前一個交易日的。
- 單位要講清楚：個股是張（股數除以 1,000），市場總額是億元。
- 連買連賣是描述，不是預測。法人也會看錯、也會停損；投信連買的股票照樣可以跌停。
- 「大買」「大賣」的標記只表示那天在全市場該法人的買超或賣超前 20 名，不代表任何建議。
- 對交易所客氣：每次查詢間隔 2 秒，已公布的日子用快取。

## 不做的事

不猜法人明天會怎麼做，不把籌碼當進場訊號，不說誰是「主力」或誰在「養股」，不推薦買或賣，
也不下單。看起來再明顯的籌碼，也要先過 trader-exit、trader-timemachine、trader-budget 和 trader-risk。

## 安全

- 這是教學與工具，不構成投資建議。PASS 只代表通過規則檢查，不是推薦。
- 預設模擬交易（`"paper": true`）。要不要動用真錢，由使用者自己在自己的設定檔決定。
- 這套 skill 不會自己下單。只有 trader-broker 會產生委託單，而且三件事都成立才會：trader-risk 今天通過了這一張單、使用者在對話中針對這一張單明確回覆 yes、使用者自己在券商 App 或下單軟體送出。
- 不做融資、融券、先賣後買、選擇權或期貨，除非設定檔開啟而且使用者確認。
- 券商帳號、密碼和憑證不在對話裡出現，也不寫進任何檔案。
